Original content

Labels, notes, evidence links, node positions, shapes and recorded colors come from the source database. Nodes and connections use four section colors on white or graphite surfaces. Cross-section connections follow their source node's section, or the destination section when the source is ungrouped. Original colors remain recorded in the source data. Notes appear only under their explicitly grouped node. Empty sections are omitted.

Local layout

Edit layout lets you move nodes and line segments with grid snapping. Changes are saved on this device. Reset restores the original layout; Undo and Redo apply to layout changes. Source text, node identities and connection direction remain unchanged.

Connection geometry

The source provides endpoints, direction, line type, color and text, but does not provide the original paths, bends or label positions. Displayed routes use separate attachment points and staggered lanes to avoid overlapping lines. All recorded curves are displayed as elbowed lines for a consistent style; recorded styles remain in the source data. Routes and label placement are approximations. An original visual export is needed to match them exactly.

Unspecified font metrics, corner radii, border widths and stacking use display defaults. Evidence links are reproduced from the source; their content has not been independently verified.
